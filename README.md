### Currently building

**[Snio](https://snio.gg)** — multi tenant esports platform, built as a public showcase.

NestJS, Prisma, React and Tailwind in a Turborepo monorepo, deployed on a two server Hetzner setup with private network isolation. It exercises the production patterns I work with day to day: row level security as a Prisma extension, request scoped context via AsyncLocalStorage, a grant based permission system with role hierarchy, and JWT with refresh rotation.

Live at [snio.gg](https://snio.gg) · code at [github.com/SyK5/snio](https://github.com/SyK5/snio)
